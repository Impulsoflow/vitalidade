# Brainstorm de Design - Calculadora SF-36

## Resposta 1: Minimalismo Médico Contemporâneo (Probabilidade: 0.08)

**Design Movement:** Minimalismo Suíço aplicado a interfaces de saúde

**Core Principles:**
- Clareza absoluta: cada elemento tem propósito funcional, nenhuma decoração
- Hierarquia tipográfica forte com espaçamento generoso
- Foco na legibilidade e acessibilidade para públicos diversos (pacientes, profissionais)
- Progressão linear e intuitiva através do questionário

**Color Philosophy:**
- Paleta neutra com toques de verde (confiança, saúde): branco, cinza claro (95%), cinza médio (50%), verde claro (para ênfase)
- Fundo branco puro para máxima legibilidade
- Verde suave para botões de ação e indicadores de progresso
- Cinza para elementos secundários

**Layout Paradigm:**
- Coluna única centrada (máx 600px) para manter foco
- Cartões brancos com sombra suave para separar seções
- Barra de progresso horizontal no topo
- Espaçamento vertical generoso entre perguntas

**Signature Elements:**
- Indicador de progresso minimalista (números + barra)
- Ícones médicos sutis (opcional, apenas para domínios)
- Resultado final em painel destacado com tipografia grande

**Interaction Philosophy:**
- Transições suaves entre perguntas
- Validação em tempo real com feedback visual
- Scroll automático para próxima pergunta após resposta

**Animation:**
- Fade-in suave ao carregar perguntas
- Slide suave ao navegar entre seções
- Pulse suave no botão "Calcular"

**Typography System:**
- Display: Poppins Bold 32px (títulos principais)
- Heading: Poppins SemiBold 20px (títulos de seção)
- Body: Inter Regular 16px (perguntas e opções)
- Small: Inter Regular 14px (instruções, labels)

## Resposta 2: Design Humanista com Warmth (Probabilidade: 0.07)

**Design Movement:** Humanismo Digital com influências de design escandinavo

**Core Principles:**
- Empatia visual: cores quentes e acolhedoras
- Tipografia generosa e confortável para leitura prolongada
- Ilustrações sutis para contextualizar domínios de saúde
- Sensação de diálogo, não de formulário clínico

**Color Philosophy:**
- Paleta quente: off-white (fundo), azul suave (primário), coral suave (secundário), verde menta (sucesso)
- Fundo com textura leve (ruído imperceptível)
- Azul suave para elementos interativos
- Coral para ênfase em avisos ou informações importantes

**Layout Paradigm:**
- Assimétrico: conteúdo principal à esquerda, barra lateral com progresso à direita
- Cartões com raio de borda maior (12px)
- Espaçamento orgânico, não grid rígido
- Ilustrações pequenas ao lado de cada domínio

**Signature Elements:**
- Ilustrações minimalistas para cada domínio (saúde física, emocional, social, etc.)
- Barra de progresso circular ao lado
- Resultado em formato de "dashboard" visual com gráficos suaves

**Interaction Philosophy:**
- Microinterações delicadas (hover effects com elevação)
- Feedback positivo ao completar seções
- Animação de celebração ao finalizar

**Animation:**
- Entrada suave com stagger para cada pergunta
- Hover com elevação e mudança de cor suave
- Animação de preenchimento de barra de progresso
- Confete suave ao finalizar (opcional)

**Typography System:**
- Display: Playfair Display Bold 36px (títulos)
- Heading: Poppins SemiBold 22px (seções)
- Body: Lato Regular 17px (perguntas - mais confortável)
- Small: Lato Regular 14px (instruções)

## Resposta 3: Design Científico Moderno (Probabilidade: 0.06)

**Design Movement:** Data Visualization meets Medical Science

**Core Principles:**
- Rigor visual: dados e números em destaque
- Paleta baseada em espectro de saúde (verde → amarelo → vermelho)
- Gráficos e visualizações como elemento central
- Confiança através de transparência de dados

**Color Philosophy:**
- Paleta de espectro: verde escuro (ótimo), verde claro, amarelo, laranja, vermelho (crítico)
- Fundo escuro (charcoal 95%) para contraste com dados
- Branco para texto principal
- Cores de domínio diferenciadas (cada um tem cor única)

**Layout Paradigm:**
- Grid assimétrico com visualizações em destaque
- Seção de perguntas à esquerda, preview de resultados à direita
- Gráfico radar ou barras horizontais para mostrar progresso em tempo real
- Tipografia grande e ousada

**Signature Elements:**
- Gráfico interativo mostrando escores em tempo real
- Código de cores por domínio (cores diferentes para cada escala)
- Tabela de referência normativa (comparação com população)

**Interaction Philosophy:**
- Hover em perguntas mostra impacto no gráfico
- Atualização em tempo real do gráfico conforme responde
- Clique em domínio mostra detalhes de cálculo

**Animation:**
- Animação de barras crescendo ao calcular
- Transição suave entre valores
- Pulse em elementos interativos

**Typography System:**
- Display: IBM Plex Mono Bold 40px (números de escores)
- Heading: IBM Plex Sans SemiBold 24px (títulos)
- Body: IBM Plex Sans Regular 16px (perguntas)
- Small: IBM Plex Mono Regular 12px (dados técnicos)

---

## Decisão Final

**Escolhido: Minimalismo Médico Contemporâneo**

Esta abordagem é ideal para uma ferramenta de saúde porque:
- Maximiza clareza e acessibilidade para usuários de diferentes idades e backgrounds
- Reduz ansiedade visual em contexto de avaliação de saúde
- Facilita compreensão rápida e resposta sem distrações
- Funciona perfeitamente em mobile (importante para contexto clínico)
- Transmite profissionalismo e confiança sem ser frio ou impessoal
